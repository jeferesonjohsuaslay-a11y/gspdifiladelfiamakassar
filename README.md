# Profile Website of GSPDI FILADELFIA MAKASSAR

The official website of GSPDI Filadelfia Congregation, Makassar (GSPDI JF-Makassar) a church established in 1966, located at Jl. Veteran Utara, Lorong 45 No. 19, Makassar.  This website features a profile of the church and its senior pastor, the church’s vision, a schedule and description of various ministries (Sunday Services, Little Heroes, F2G Youth Service, General Prayer & Fasting, Family Services, and Prayer Ministry), a gallery highlighting church activities, location information, as well as contact details and links to the congregation’s social media channels.
